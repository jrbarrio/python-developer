# Installation

## Stable release

To install impyrial, run this command in your terminal:

```sh
uv add impyrial
```

Or if you prefer to use `pip`:

```sh
pip install impyrial
```

## From source

The source files for impyrial can be downloaded from the [Github repo](https://github.com/audreyfeldroy/impyrial).

You can either clone the public repository:

```sh
git clone git://github.com/audreyfeldroy/impyrial
```

Or download the [tarball](https://github.com/audreyfeldroy/impyrial/tarball/master):

```sh
curl -OJL https://github.com/audreyfeldroy/impyrial/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd impyrial
uv pip install .
```
